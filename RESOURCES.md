# Git Learning Resources

A curated list of excellent resources to deepen your understanding of Git and version control.

## Books

- **[Pro Git](https://git-scm.com/book/en/v2)** by Scott Chacon and Ben Straub. The definitive, open-source guide to Git.
- **[Version Control with Git](https://www.oreilly.com/library/view/version-control-with/9781449345037/)** by Jon Loeliger and Matthew McCullough. A comprehensive dive into Git's capabilities.
- **[Git Pocket Guide](https://www.oreilly.com/library/view/git-pocket-guide/9781449327507/)** by Richard E. Silverman. A handy quick reference for daily commands.

## Official Resources

- **[Git Documentation](https://git-scm.com/doc)** - The official reference manual.
- **[Git Book](https://git-scm.com/book/en/v2)** - The official Pro Git book available online.
- **[GitHub Docs](https://docs.github.com/en)** - Comprehensive guides on using Git with GitHub.

## Practice Resources

- **[Learn Git Branching](https://learngitbranching.js.org/)** - An interactive, visual tool for learning Git branching concepts.
- **[GitHub Skills](https://skills.github.com/)** - Interactive courses built into GitHub repositories to help you learn Git and GitHub workflows.

## Video Resources

- **[Git and GitHub for Beginners - Crash Course](https://www.youtube.com/watch?v=RGOj5yH7evk)** by freeCodeCamp.
- **[Advanced Git Tutorial](https://www.youtube.com/watch?v=Uszj_k0DGsg)** by Atlassian.

## Community Resources

- **[Stack Overflow - Git Tag](https://stackoverflow.com/questions/tagged/git)** - The best place to find answers to specific Git problems.
- **[r/Git](https://www.reddit.com/r/git/)** - The official Git subreddit.

## Advanced Resources

- **[Git from the Bottom Up](https://jwiegley.github.io/git-from-the-bottom-up/)** by John Wiegley. A deep dive into Git's internal architecture and object model.
- **[Missing Semester of Your CS Education - Version Control](https://missing.csail.mit.edu/2020/version-control/)** - MIT's excellent primer on how Git actually works under the hood.
